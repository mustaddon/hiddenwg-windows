# [HiddenWG](https://github.com/mustaddon/hiddenwg/) for Windows

This repository is a [fork](https://github.com/WireGuard/wireguard-windows/) that adds obfuscation to the standard [WireGuard](https://www.wireguard.com/) protocol.

## Download &amp; Install

[Standalone MSIs](https://github.com/mustaddon/hiddenwg-windows/releases/) &ndash; Select the latest version for your architecture.
